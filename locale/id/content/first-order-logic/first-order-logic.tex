\olpart{fol}{Logika Orde Pertama}

\begin{editorial}
  Bagian ini membahas metateori logika orde pertama hingga teorema
  kelengkapan. Saat ini pembahasannya tidak bergantung pada pembahasan
  terpisah mengenai logika proposisi; semuanya dibuktikan. Berkas sumber akan
  mengecualikan materi mengenai kuantor (serta mengganti ``!!{structure}''
  dengan ``!!{valuation}'', $\Struct{M}$ dengan $\pAssign{v}$, dan
  seterusnya) jika tag ``FOL'' bernilai salah. Bahkan, sebagian besar materi
  dalam bagian mengenai logika proposisi hanyalah materi orde pertama dengan
  tag ``FOL'' dinonaktifkan.

  Jika bagian mengenai logika proposisi disertakan, hal ini menimbulkan
  banyak pengulangan. Namun, direncanakan agar bagian ini dapat memperhitungkan
  materi mengenai logika proposisi (dan mengecualikan materi yang sudah
  dibahas, sekaligus mempersingkat bukti dengan merujuk ke bagian-bagian yang
  bersesuaian dalam bagian proposisi).
\end{editorial}
