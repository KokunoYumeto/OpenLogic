# Turkish localization

The Turkish localization lives in [`locale/tr/`](locale/tr/README.md).

The current cumulative reader checkpoint covers OLP-0001 through OLP-0062:
the translated front matter and routing modules, the complete introductory
Sets, Relations, Functions, Size of Sets, Arithmetization, and Infinite Sets
chapters, and the complete reader-reachable Propositional Logic `Syntax and
Semantics` chapter. It is built directly inside this mirror from the Open Logic
Project source tree, with no English fallback modules in the checkpoint
driver.

The complete localization remains in progress. Current exact coverage is
62/722 tracked content modules; the continuation cursor is OLP-0063.
