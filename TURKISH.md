# Turkish localization

The Turkish localization lives in [`locale/tr/`](locale/tr/README.md).

The current cumulative reader checkpoint covers OLP-0001 through OLP-0040:
the translated front matter and routing modules plus the complete introductory
Sets, Relations, Functions, and Size of Sets chapters. It is built directly
inside this mirror from the Open Logic Project source tree, with no English
fallback modules in the checkpoint driver.

The complete localization remains in progress. Current exact coverage is
40/722 tracked content modules; the continuation cursor is OLP-0041.
